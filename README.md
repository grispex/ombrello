# Ombrello

Libreria neutrale e consultabile delle proposte politiche dei partiti italiani presenti in Parlamento, con mappa dei punti di contatto (touchpoint) tra partiti.

- `metodo/`: regole di raccolta (codebook), aree tematiche, schema dei dati
- `strumenti/`: script per scaricare le fonti e validare le proposte (ogni citazione deve comparire nel testo della fonte)
- `corpus/`: testo integrale delle fonti
- `dati/`: partiti, fonti e proposte (una riga JSON per voce)

Stato: raccolta in corso, dati provvisori. Fotografia al 16 ottobre 2026.
